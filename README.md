# Thomas Dental Website

A sophisticated, responsive website for Thomas Dental—a boutique private dental practice in Boca Raton, Florida.

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Design System

- **Primary Navy:** #102B3F
- **Muted Ocean Blue:** #527C91
- **Warm Off-White:** #F7F5F0
- **Typography:** DM Serif Display (headings), Inter (body)

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
